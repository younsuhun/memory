4.  검증된  콘텐츠  공식  (5/12  떡상  기반 )  
공식명 :  면죄부  +  메커니즘  +  자기수용

[ 마무리 ]  너  =  정상임  /  진화적으로  합리적임  /  평범한  사람  아님

•  결론  =  자기  수용  ( 감정적  보상 )  
훅  패턴  ( 다양화  필수 )  
•  질문형 :  " 왜  누구는  X 일까 ?"  
•  면죄부형 :  "X  하는  사람 ?  너  잘못  아님 "  
•  통념  부정형 :  "X  =  Y 라는  통념 .  거짓말이야 "  
•  정체성형 :  "X  하는  사람 ?  그게  너  ___  회로야 "  
•  고백형 :  "30 살까지  몰랐던  X"  
주의 :  같은  훅  패턴  4 편  연속  X.  알고리즘  자기복제  패널티 .
